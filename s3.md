# s3


Setup directory:
```
mkdir -p ~/.aws
```

Setup credentials
```
cat << EOF > ~/.aws/credentials
[default]
aws_access_key_id = JZKVM989DLG7F1GTZGM0
aws_secret_access_key = M5TbbKjLC2ZEA1CbrZoYCaqXpeu4QowjjvlsOtLW
EOF
```

Setup config
```
cat << EOF > ~/.aws/config
[default]
region = us-east-1
endpoint_url = https://ceph-s3.k8s.shubhamtatvamasi.com
EOF
```

Create new bucket:
```bash
aws s3 mb s3://my-first-bucket
```

Check bucket list:
```bash
aws s3 ls
```
